# 🧬 FoldScout

**AI-powered structural review for the AlphaFold era.**

From a UniProt ID, PDB ID, or raw amino acid sequence to an expert-level structural report — grounded in real database facts, not LLM guesses — in under 30 seconds.

## Why "FoldScout"?

The name comes from two ideas that defined the product:

| Part            | Meaning                                                                                                                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Fold**  | Protein**folding** — a nod to **AlphaFold** and the wider structure-prediction era this tool is built for.                                                                          |
| **Scout** | A**scout** runs ahead of the army. Before a structural biologist commits to a deep workflow (PyMOL, MD, docking), FoldScout does the fast first-pass triage: confidence, domains, caveats. |

It follows the naming pattern of well-known structural biology tools like **FoldX** and **FoldSeek**, so the intent is recognizable to the target community at a glance.

---

## What it does

1. Paste a **UniProt ID** (e.g. `P04637`), a **PDB ID** (e.g. `1TUP`), or a raw **amino acid sequence**.
2. FoldScout fetches the structure from **AlphaFold DB**, **RCSB PDB**, or folds your sequence with **ESMFold**.
3. It parses **per-residue pLDDT**, identifies confidence regions, fetches **UniProt features** (domains, active sites, binding sites, etc.), and pulls **AlphaMissense** per-residue pathogenicity when available.
4. A grounded, hallucination-controlled report is generated by **Gemini 2.5 Flash** — every residue range it cites comes from the data layer above, not from the LLM's imagination.

The full pipeline runs in ~10–30 seconds depending on the entry.

## Key features

- 🧬 **AlphaFold DB + RCSB PDB lookup** by UniProt or PDB ID
- 🧪 **Sequence input mode** — paste a sequence, get an ESMFold prediction
- 🛡️ **Grounded AI report** — UniProt features injected into the prompt, `temperature: 0.2`, strict anti-hallucination instructions
- 🎨 **3D viewer** (3Dmol.js) with three coloring modes: **pLDDT**, **Spectrum**, **AlphaMissense**
- 📊 **Per-residue pLDDT chart** with confidence bands
- 🧫 **AlphaMissense overlay** (per-residue pathogenicity, when available for the UniProt entry)
- 🔀 **Compare mode** — side-by-side analysis of two proteins
- 🌐 **Language toggle (한국어 / English)** — switching language automatically regenerates the report

## Why this matters

After AlphaFold, the bottleneck shifted from *predicting* structures to *interpreting* them. Every structural biologist still opens PyMOL, manually colors by B-factor, scrolls through pLDDT plots, browses UniProt, and writes their own first-pass assessment. FoldScout automates that first-pass review so researchers can focus on the science — without paying the typical LLM "confidently wrong" tax.

## Anti-hallucination strategy (the core differentiator)

LLM-generated structural commentary is notoriously prone to invented residue numbers and made-up domains. FoldScout addresses this with **four layered controls**:

1. **UniProt grounding** — every reviewed entry's features (Domain, Region, Binding site, Active site, DNA binding, etc.) are fetched from `rest.uniprot.org` and **injected into the prompt as authoritative ground truth**.
2. **Strict prompt rules** — the model is instructed in plain language never to invent residue numbers, never to cite missing publications, and to write "this is uncertain" when unsure.
3. **Low temperature** — `temperature: 0.2` discourages embellishment.
4. **Source transparency** — the UI shows a "grounded in UniProt facts" badge and an expandable list of every feature used in the prompt, so users can audit the report against the ground truth.
